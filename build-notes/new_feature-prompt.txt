── SPEC: Chord Progression Analysis ──────────────────────────────────────

Data needed (hardcode in chords.js):
  DIATONIC_CHORDS = {
    'C':  ['C','Dm','Em','F','G','Am','Bdim'],
    'G':  ['G','Am','Bm','C','D','Em','F#dim'],
    ... all 12 major keys
  }
  ROMAN_NUMERALS = ['I','ii','iii','IV','V','vi','vii°']
  CHORD_FEEL = {
    'I':   'Home — stable, resolved',
    'ii':  'Gentle tension',
    'iii': 'Dreamlike, uncertain',
    'IV':  'Lift, movement',
    'V':   'Strong tension, wants to resolve',
    'vi':  'Melancholic, emotional',
    'vii°':'Unstable, dramatic',
  }

Algorithm:
  1. Get Chords_Used list
  2. Detect key from post.Key (strip minor 'm' if present)
  3. For each chord in Chords_Used, find its position in diatonic scale
  4. Assign Roman numeral
  5. Identify common patterns: I-V-vi-IV, I-IV-V, ii-V-I, etc.

HTML output (collapsible panel, default closed):
  <div class="chord-progression-panel">
    <button class="chord-prog-toggle">
      ♩ Chord Analysis <span>▸</span>
    </button>
    <div class="chord-prog-body" hidden>
      <div class="chord-prog-key">Key of G major</div>
      <div class="chord-prog-table">
        [G → I — Home], [Em → vi — Melancholic], etc.
      </div>
      <div class="chord-prog-pattern">
        Common pattern: I–vi–IV–V (50s progression)
      </div>
    </div>
  </div>

Placement: Between .chord-detail-header and .chord-controls
CSS: Add .chord-progression-panel, .chord-prog-* to css/chords.css

── SPEC: Beginner Simplification Mode ────────────────────────────────────

Constant (hardcode in chords.js):
  const SIMPLIFY_MAP = {
    'Cmaj7':'C', 'Dmaj7':'D', 'Emaj7':'Em', 'Fmaj7':'F',
    'Gmaj7':'G', 'Amaj7':'A', 'Bmaj7':'B',
    'Dm7':'Dm', 'Em7':'Em', 'Am7':'Am', 'Bm7':'Bm',
    'Dsus2':'D', 'Dsus4':'D', 'Asus2':'A', 'Asus4':'A',
    'Gsus2':'G', 'Gsus4':'G', 'Csus2':'C', 'Csus4':'C',
    'Cadd9':'C', 'Gadd9':'G', 'Dadd9':'D',
    'C7':'C', 'D7':'D', 'G7':'G', 'A7':'A', 'E7':'E',
    'F':'Fmaj7',    ← F is hard, offer Fmaj7 (easier shape)
    'Bm':'D',       ← Bm barre is hard, offer D as substitute
    'B':'Bm',       ← B barre is hard, offer Bm
    'F#m':'Am',     ← F#m barre, offer Am as rough sub
  }

Logic:
  - Add button to .chord-controls bar: "Simplify ✓"
  - When toggled ON: re-render tab passing simplified chord names
    function simplifyChord(name) { return SIMPLIFY_MAP[name] || name; }
    Pass through renderTab() with a simplify flag
  - When toggled OFF: re-render with original chord names
  - Show badge "Beginner Mode" next to song title when active
  - Persist in localStorage 'sd5_beginner_mode' (boolean)
