├── js/router.js (~280 lines)
│   Purpose: SPA navigation engine
│   Exports: registerRoute(path, handler), registerPrefix(prefix, handler),
│            navigate(rawPath, push=true), boot(), showView(viewId)
│   Does:
│     • Maintains _exactRoutes Map and _prefixRoutes Array
│     • navigate(rawPath, push=true):
│         - Parses URL + query params
│         - Normalises path (removes /portfolio-upload, strips index.html)
│         - Checks cache to avoid double-render
│         - Calls pStart() for progress bar
│         - Hides all .view elements (removes .active class)
│         - Updates nav aria-current="page" on matching link
│         - Pushes to history if push=true
│         - Scrolls to top (behavior:'instant')
│         - Decomposes path into parts[] and slug
│         - Dispatches to exact route handler first
│         - Falls back to prefix routes (first match wins)
│         - 404: shows overlay if no handler found
│         - Calls showView() to activate the right DOM element
│         - Calls pEnd() when done
│     • Global [data-link] click handler:
│         - Intercepts all <a data-link> clicks
│         - Prevents default for internal links only
│         - Calls navigate(href)
│     • Popstate handler: navigate(location.pathname + location.search, false)
│     • Mobile burger menu: toggles nav-links visibility on click
│   Does NOT know: any view names, any render functions, SEO details

├── js/api.js (~350 lines)
│   Purpose: Data fetching, CSV parsing, local caching
│   Exports: fetchSheet(endpoint, key, onRevalidate), parseCSV(raw),
│            cGet(key), cSet(key, data), cDel(key), CFG, buildImgMap, buildFAQ
│   CFG object contains:
│     siteUrl: "https://suman-dangal.com.np"
│     cacheMins: 10  ← localStorage TTL in minutes
│     postsPerPage: 6
│     chordsPerPage: 12
│     api: {
│       blog: '/api/data?sheet=blog',
│       skills: '/api/data?sheet=skills',
│       projects: '/api/data?sheet=projects',
│       exp: '/api/data?sheet=exp',
│       about: '/api/data?sheet=about',
│       faq: '/api/data?sheet=faq',
│       images: '/api/data?sheet=images',
│       featured: '/api/data?sheet=featured',
│       chords: '/api/data?sheet=chords'
│     }
│   fetchSheet(endpoint, key, onRevalidate):
│     - Checks localStorage with prefix 'sd5_' and 10-min TTL
│     - If FRESH cache: returns immediately (no network)
│     - If STALE cache: returns stale data, fetches fresh in background,
│       calls onRevalidate(fresh) if provided
│     - If NO cache: fetches, waits for response, caches, returns
│   parseCSV(raw):
│     - Handles quoted fields, escaped quotes (""), CRLF + LF
│     - Strips empty rows
│     - Returns Array<Object> keyed by header row
│   cGet(key) / cSet(key, data) / cDel(key):
│     - localStorage helpers with 'sd5_' prefix
│     - Errors swallowed (private browsing doesn't throw)
│   buildImgMap(post, imageRows):
│     - Resolves Img1_URL...ImgN_URL columns + images sheet rows
│     - Returns { '[img1]': '<figure>...</figure>', ... }
│   buildFAQ(slug, rows):
│     - Fetches FAQ rows for blog slug, injects FAQPage schema
│     - Returns rendered HTML string
│   Does NOT: touch DOM, call fetch on behalf of views
│

├── js/utils.js (~600 lines)
│   Purpose: Shared utilities (no DOM manipulation at module level)
│   Exports: esc(s), fixImgUrl(url), sanitizeHTML(raw), md(text, imgMap),
│            watchReveals(), pStart(), pEnd(), loadCSS(href),
│            showToast(message, duration)
│   esc(s): 
│     - Escapes &<>"' for safe innerHTML insertion
│     - MUST be called on ALL sheet data before innerHTML
│   fixImgUrl(url):
│     - Converts Google Drive URLs to lh3.googleusercontent.com
│     - Non-Drive URLs passed through unchanged
│   sanitizeHTML(raw):
│     - Whitelist-based HTML sanitizer
│     - Safe tags: table, tr, th, td, strong, em, a, ul, ol, li, code, pre
│     - Strips disallowed attributes, forces safe link behaviour
│   md(text, imgMap):
│     - Markdown-ish renderer:
│       ## h2, ### h3, > blockquote
│       - unordered, 1. ordered lists
│       **bold**, *italic*, `code`, [text](url)
│       ``` code blocks
│       | as line separator (Google Sheets compatible)
│       [img1] [img2] inline image placeholders → resolved via imgMap
│     - Returns HTML string safe for innerHTML
│   watchReveals():
│     - Hooks IntersectionObserver onto all .reveal elements
│     - Staggered fade-up animation on scroll
│     - Threshold 0.07, rootMargin '0px 0px -40px 0px'
│     - Module singleton (one observer instance for app lifetime)
│   pStart() / pEnd():
│     - Drives #nprogress bar during navigation
│     - pStart(): resets to 0%, animates to ~80%
│     - pEnd(): completes to 100%, fades after 380ms
│   loadCSS(href):
│     - Lazily loads section CSS files on demand
│     - Guards against double-injection with internal Set
│     - Returns Promise that resolves when sheet is loaded
